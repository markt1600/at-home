# Generated game artwork

Created using the built-in image-generation tool for this project. These are fictional adults, not photographs of real people.

- `public/art/visitors.png`: twelve photographic-style portraits in a 4×3 atlas. The game selects a cell for each character and renders it at the door. Hidden visitor assignments remain randomized independently of the artwork.
- `public/art/house-surfaces.png`: 2×2 atlas: ivory plaster, sage cabinetry, pale marble and oak. Applied to the house geometry with material maps and bump detail.
