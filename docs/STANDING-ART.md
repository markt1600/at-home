# Standing visitor artwork

Generated with the built-in image generation tool, using the earlier fictional portrait atlas as the identity reference. Each final atlas contains three complete adults in one row. The initial transparent-background request returned an opaque checkerboard, so the selected images were edited to a solid magenta background. The game removes that background with a chroma key while preserving dark hair and clothing, then finds each person's bounds to place their shoes at floor level.

Keep the exact three people, faces, skin, hair, bodies, clothes, hands, shoes, poses, pixel positions, full-body framing, and square three-column layout unchanged. Do not add shadows, floor, scenery, text, or anything else. Preserve all facial and clothing detail. Background ONLY changes to solid vivid magenta. No magenta reflections or tint on the people.
